사진·텍스트 질문, AI 풀이, 오답 노트와 복습을 위한 개인용 Android 학습 앱입니다. 계정 시스템이나 개발자 서버는 없습니다.
zsz가 DeepSeek-V4/V4.1 및 GPT-6.1 Sol의 도움으로 개발했습니다. 설치 파일은 [GitHub Releases](https://github.com/ShizhenZhou/StudyAssistant/releases)에서 받으세요.

## 기능

- 📷 텍스트와 최대 3장 이미지로 질문. 자동·수동 영역 선택 및 손글씨 답안 채점.
- 🤖 스트리밍 풀이, 이미지 후속 질문, 생성 중단·계속, 유사 문제 연습, KaTeX 수식.
- 🧠 AI 관리는 API 관리(사용량 포함), AI 이미지 자르기, 풀이 설정, 사용자 지침으로 구성됩니다. 빠른 모드와 사고 모드 모두 `deepseek-flash`를 사용하며 사고 기능을 각각 끄거나 켭니다. AI 출력 언어는 UI 언어와 별도입니다.
- 📚 오답 분류·태그·검색·정렬·일괄 처리.
- 🕘 풀이 기록은 최초 풀이·글/이미지 질문·채점을 **최근 200건, 30일 이내** 보관합니다. 후속 질문은 같은 기록을 갱신하고 최초 시각을 유지하며, 노트·복습에서 열면 새 기록을 만들지 않습니다.
- 🏷 AI 제안이나 수동 태그 그룹을 미리 보고 확인 후 병합하며, 최근 병합을 취소할 수 있습니다. 정리 초안을 자동 저장하고 최근 20건의 로컬 AI 분석 진단을 수동 내보낼 수 있습니다.
- 📖 `0/1/2/4/7/15/30`일 복습 일정, 학습 통계와 매일 알림.
- 🌐 중국어 간체·번체, 영어, 일본어, 한국어 UI, 테마와 전체 글자 크기.
- 📦 ZIP 백업은 이미지 중복 제거와 대용량 분할을 지원하며 구형 v3 JSON도 가져옵니다. 이름은 `SABak-타임스탬프.zip`, 분할 시 `-1of3`을 추가합니다. 복원 시 모든 분할 파일을 선택하세요. 같은 문제 ID는 로컬 내용을 유지하고 새 문제에만 분류·태그를 가져옵니다.
- 🗄️ 자동 백업은 `SABak_auto-` 이름으로 매일 앱을 연 뒤 약 30초부터 실행 기회를 기다립니다. 당일 완전한 수동·자동 백업이 있거나 노트가 비어 있으면 생략하고, 그 외에는 변경이 없어도 매일 저장합니다. 대기 중 자동 작업은 즉시 백업으로 인계하며 페이지를 떠나도 계속됩니다. 시작 전 완전한 자동 백업이 **3세트 초과**이면 최신 **2세트**, 성공 후에는 **3세트**를 유지합니다. 구형 이름도 정리하지만 수동·손상·누락·식별 불가 파일은 보존합니다. 전경 성공은 앱 내 안내, 배경 최종 실패는 권한이 있을 때 시스템 알림으로 표시합니다.
- 💾 저장 실패 재시도, 재시작 후 저장된 사본 복구, 충돌 시 덮어쓰기 방지, 미저장 내용 수동 내보내기.
- 💬 재생성이 성공할 때까지 이전 답변을 유지합니다. 중단된 대화는 별도 로컬 초안으로 홈·데이터 관리에서 복구합니다. 일반 백업에는 포함하지 않으며 구조용 내보내기로 수동 복구를 돕습니다.
- ↩️ 문제·풀이 기록·분류 삭제 후 3초 동안 취소할 수 있습니다. 복습은 해당 회차의 선택 범위를 유지하며 AI 채점 제안은 확인이 필요합니다. 일간·주간·연속일·추세는 최근 복습 날짜로 추정합니다.
- ⬆️ 앱 업데이트는 Android 백그라운드 다운로드를 사용합니다. 페이지를 떠나도 진행하고 돌아오면 상태를 복원합니다. 알림에서 진행 확인·업데이트 페이지 이동·취소가 가능하며 알림이 제한되어도 다운로드합니다. 실시간 표시는 기기 OS에 따라 달라 실제 기기 확인이 필요합니다. 연결 복구 후 재개를 시도하고 같은 버전은 UTC 빌드 시각으로 비교합니다. 호환 정보로 지원하지 않는 OS의 다운로드를 차단하며 설치 전 실제 최소 OS·서명·버전·SHA-256을 확인합니다.

## 데이터와 개인정보

문제·풀이 기록·복습 DB는 기기에 보관합니다. 필요한 문제·이미지·문맥·사용자 지침·관련 분류 및 태그 이름·매개변수만 본인 Key로 **DeepSeek 공식 API**에 직접 전송합니다. 개발자 서버를 거치지 않으며 Key는 Android Keystore로 암호화해 저장합니다.

태그 정리 → AI 분석을 직접 실행하면 전체 태그 ID·이름·연결된 문제 수를 전송합니다. 문제 본문·답변·이미지는 보내지 않습니다. 업데이트는 문제 내용을 포함하지 않고 GitHub에 접근합니다. 이용 통계 전송은 없습니다.

자동 백업은 SAF에서 선택한 폴더에만 기록합니다. 앱은 클라우드 동기화를 시작하지 않지만 클라우드 저장소 앱은 자체 동기화할 수 있습니다. 충돌 로그와 AI 진단은 수동 내보내기 때만 지정한 위치에 저장합니다.

## 기술 구성

Kotlin **2.2.20** · Jetpack Compose / Material3 · MVVM · Room **2.8.4**(DB v10) · Retrofit / OkHttp(SSE) · kotlinx.serialization · CameraX · WebView / KaTeX · Navigation Compose · WorkManager **2.12.0**(일회성 백업) · AlarmManager · Android Keystore.

AGP **8.13.0**, Gradle wrapper **8.14**, JDK **21**; compileSdk / targetSdk **37**, minSdk **36**(Android **16+**), build-tools **36.0.0**. 백업 v4는 ZIP / DEFLATE를 사용하며 v3 JSON을 가져올 수 있습니다. [DATA_SCHEMA.md](DATA_SCHEMA.md)를 참고하세요.

## 개발과 테스트

[AGENTS.md](AGENTS.md), [개발 절차](docs/development.md), [격리 Android 테스트](docs/testing/reliability.md)를 참고하세요. 영문 작업 경로를 권장합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check-project.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check-project.ps1 -Mode Full
```

기본은 Basic 검사이며 관련 단위 테스트는 `-TestClass`로 선택합니다. Full은 전체 로컬 회귀가 명확히 필요한 경우만 사용합니다. 캐시·보고서는 프로젝트에 보관합니다. 테스트 수는 해당 CI 보고서를 따르며 기기 테스트는 별도 패키지와 인공 데이터만 사용합니다.

## 인증 정보와 릴리스

공개 저장소입니다. API Key·토큰·서명 자료·로컬 설정·실제 문제·백업을 커밋하거나 CI에 첨부하지 마세요. `.githooks` 검사는 변경 내용 검토를 대신하지 않습니다.

**로컬 기본 검사 → main 병합 → 한 번의 릴리스 CI → 로컬 서명 → 배포·다운로드 검증·보관**. CI는 미서명 후보와 인공 데이터 테스트만 처리합니다. 개인키와 암호는 로컬에서만 사용하고 원래 인증서와 lineage로 재컴파일 없이 서명한 뒤 코드·리소스 일치를 확인합니다.

`tools/release.ps1`의 start/status/verify/publish가 로컬 진행 상태와 재개를 관리합니다. main push와 tag는 다시 빌드하지 않으며 기존 tag를 이동하거나 공개 버전을 자동 교체하지 않습니다. 명령·업로드 범위·Git/API 역할은 개발 절차를 참고하세요. 내부 설계·조사·버전별 과정 기록은 로컬에만 보관합니다.
