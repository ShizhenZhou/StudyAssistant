写真・テキスト質問、AI解答、誤答ノートと復習のための個人用Android学習アプリです。アカウント機能や開発者運営のサーバーはありません。
zsz が DeepSeek と GPT の支援で開発。公開版は [GitHub Releases](https://github.com/ShizhenZhou/StudyAssistant/releases) から入手できます。

## 機能

- 📷 テキストと最大3枚の画像で質問。自動・手動の範囲選択、手書き答案の採点に対応。
- 🤖 ストリーミング解答、画像付き追加質問、生成の停止・続行、類題練習、KaTeX数式表示。
- 🧠 AI管理はAPI管理（使用量を含む）、AI切り抜き、解答設定、カスタム指示の4ページ。高速・思考モードとも `deepseek-flash` を使い、思考を無効・有効に切り替えます。出力言語は表示言語と別に設定できます。
- 📚 誤答を分類・タグ・検索・並べ替え・一括操作で整理。
- 🕘 解答履歴は初回解答・文字/画像質問・採点を**最新200件、30日以内**保持。追加質問は同じ履歴を更新し、初回時刻を維持。ノート・復習から開いても履歴を追加しません。
- 🏷 タグのAI提案・手動グループをプレビューしてから統合。直近の統合を取り消せます。整理の下書きを自動保存し、AI分析の直近20件の端末内診断を手動エクスポートできます。
- 📖 `0/1/2/4/7/15/30` 日の復習間隔、学習統計、毎日の通知。
- 🌐 簡体字・繁体字中国語、英語、日本語、韓国語、テーマと全体の文字サイズに対応。
- 📦 ZIPバックアップは画像重複排除・大容量分割に対応し、旧v3 JSONも読み込めます。名前は `SABak-日時.zip`、分割時は `-1of3` を追加。復元時は全部の分割ファイルを選択します。同じ問題IDは端末内の内容を優先し、新規問題だけに分類・タグを取り込みます。
- 🗄️ 自動バックアップは `SABak_auto-` を使用し、毎日の起動から約30秒後に実行機会を待ちます。当日に完全な手動・自動バックアップがある場合やノートが空の場合は省略し、それ以外は変更がなくても毎日保存。待機中の自動処理は「今すぐバックアップ」で引き継げ、ページを離れても継続します。開始前に完全な自動バックアップが **3組超** あれば最新 **2組** を残し、成功後は **3組** を保持。旧命名も整理対象ですが、手動・破損・欠落・不明ファイルは保持。前景の成功はアプリ内表示、背景の最終失敗は許可があれば通知します。
- 💾 保存失敗の再試行、保存済みコピーの再起動後復旧、競合時の上書き防止、未保存内容の手動出力。
- 💬 再生成は成功まで旧解答を保持。中断した会話は端末内の独立した下書きとしてホームやデータ管理から復旧できます。通常バックアップには含めず、救援用出力で手動復旧を支援します。
- ↩️ 問題・解答履歴・分類の削除後3秒間は取り消し可能。復習中の対象範囲を固定し、AI採点案は確認後に適用。日別・週別・連続日数・傾向は直近の復習日から推定します。
- ⬆️ アプリ更新はAndroidの背景ダウンロードを使用。ページを離れても継続し、戻ると進捗を復元。通知から進捗確認・ページ移動・取消ができ、通知が制限されても取得は継続します。ライブ表示は端末側の判断で、実機確認が必要です。通信復旧後に再開を試みます。同一バージョンはUTCビルド時刻で比較。互換情報で非対応OSの取得を止め、インストール前に実際の最低OS、署名、バージョン、SHA-256を検証します。

## データとプライバシー

問題・解答履歴・復習DBは端末内に保存します。必要な問題文、画像、文脈、カスタム指示、関連分類・タグ名とパラメーターを、ご自身のKeyで **DeepSeek公式API** に直接送信します。開発者サーバーは経由せず、KeyはAndroid Keystoreで暗号化して保存します。

「タグ整理 → AI分析」を明示的に実行すると、全タグのID・名前・関連問題数を送信します。問題本文・解答・画像は送信しません。更新は問題内容を含めずGitHubに接続します。利用統計の送信はありません。

自動バックアップ先はSAFで選択したフォルダーのみです。アプリはクラウド同期を行いませんが、クラウドストレージ側が独自に同期する場合があります。クラッシュログとAI診断は手動出力時のみ選択先へ書き込みます。

## 技術構成

Kotlin **2.4.21** · Jetpack Compose / Material3 · MVVM · Room **2.8.5**（DB v10）· Retrofit / OkHttp（SSE）· kotlinx.serialization · CameraX **1.6.2** · WebView / KaTeX **0.19.1** · Navigation Compose · WorkManager **2.12.0**（単発バックアップ）· AlarmManager · Android Keystore。

AGP **9.4.0**、Gradle wrapper **9.8.2**、JDK **25**、compileSdk / targetSdk **37**、minSdk **36**（Android **16+**）、build-tools **36.0.0**。Bak v4はZIP / DEFLATEを使用し、v3 JSONの取込に対応。[DATA_SCHEMA.md](../DATA_SCHEMA.md) を参照してください。

## 開発とテスト

Develop/機能ブランチで開発 → 必要最小限のローカル検証 → 必要に応じBeta実機テストとADB補助 → 関連箇所の修正・再確認 → 規約に従いmainへ統合 → CIで一度ビルド → 署名・公開。

`tools/check-project.ps1` は通常、差分と機密情報のみ確認します。必要な場合だけ `-Compile` またはクラス/メソッド指定の `-TestClass` を使用します。全件テストやエミュレーターを既定で実行せず、ローカルとオンラインで重複させません。機能開発で検証範囲を勝手に拡大せず、操作感は利用者に実機確認を依頼します。[開発手順](../development.md) と [AGENTS.md](../../AGENTS.md) を参照してください。

## 認証情報とリリース

CIは手動で未署名APKと識別情報を生成します。通常はJVM・ツール・端末テストを実行せず、push/PR/tagによる重複ビルドも行いません。コミットとマージにはfeat:/fix:/build:/ci:などの接頭辞を使用します。

検証後mainへ統合・pushしてから `tools/release.ps1 start --version VERSION` → `status` → `publish --run RUN_ID` を使用します。既存証明書とlineageはローカルでのみ使用し、APKの識別情報・コード・リソースを照合します。公開ファイルを実際にダウンロードしてハッシュを確認し保存します。最低Android要件と正式/Betaの区別を保持し、既存タグは移動しません。Key、署名情報、実データ、バックアップ、端末ログをCIへ送信しません。

## API Keyと権限

設定 → AI管理 → API管理でご自身のDeepSeek Keyを入力。[公式コンソール](https://platform.deepseek.com) で取得・管理できます。

機能に応じて通信・カメラ・通知・復習アラームと起動後復元・背景実行・アプリインストール権限を使います。画像選択はシステムのフォトピッカーを使用。位置・連絡先・マイクは不要です。通知・正確なアラーム・背景動作はOS権限と省電力設定に依存します。
