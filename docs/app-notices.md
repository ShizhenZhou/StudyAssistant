# 应用公告与版本不稳定提示

应用读取 main 分支的 [`config/app-notices.json`](../config/app-notices.json)。该文件独立于 Release、Latest 和 APK；修改它不需要构建应用。首次使用前，需要先发布并安装包含这项功能的应用，旧版不会自动获得此能力。

当前文件为空，不会产生任何公告或不稳定提示。这里只预留能力，不标记任何实际版本。

## 发布与撤回

1. 编辑 main 分支的配置文件，不在 Compatible 分支另建配置源。
2. 每次改动都增加顶层 `revision`。保持 `schema` 为 `1`。
3. 普通公告放入 `announcements`，已安装版本的风险提示放入 `unstableVersions`，两个数组均可保留多条记录。
4. 每条记录使用永久且全文件唯一的 `id`，格式为 `yyyyMMdd-HHmmss-NN`，例如 `20261117-173000-01`。编号时间统一按北京时间填写；`NN` 区分同一秒创建的记录。不要因修改正文或调整数组顺序而更换编号，不重复使用旧编号。
5. 新条目的 `revision` 从 `1` 开始。仅修正文案时保持该值；确实需要已经确认过的用户再次阅读时才增加。顶层修订和条目修订用途不同。
6. 删除条目并增加顶层修订即可撤回；设置 `expiresAt` 也能自动结束展示。全部撤回时保留合法的空数组，不删除文件或改成无效 JSON。

应用按“编号 + 条目修订”持久记录确认状态。点击“知道了”、返回或点击弹窗外部均视为确认；未确认就退出应用，下次仍可能提示。更新应用、旋转或重启不会清除已经确认的记录。清除应用数据/重装会清除本机确认记录。

未读的不稳定提示优先于普通公告，同类按配置数组顺序逐条显示，一次只弹一条。提示仅在主页空闲时出现，让位于更新、数据升级和崩溃提醒，不打断解题。公告正文按纯文本显示，不支持脚本或任意远程跳转。

## 版本与展示规则

| 字段 | 规则 |
|---|---|
| `distributions` | 必填，`main`、`compat` 或两者；防止相同版本号跨分支误提示 |
| `channels` | 必填，`stable`、`beta` 或两者 |
| `versions` | 精确版本列表，可带 `v` 和 `_beta1` 等完整后缀 |
| `minVersion` / `maxVersion` | 包含边界的版本范围；只给下限表示该版本及以上；与非空 `versions` 互斥 |
| `minVersionCode` / `maxVersionCode` | 可选的额外构建范围，用于区分同版本号的不同构建；与版本条件同时满足 |
| `startsAt` | 可选，预约开始时间 |
| `expiresAt` | 必填，达到截止时间不再展示 |
| `title` / `body` | 语言代码到纯文本的映射；简体中文必填，建议同时维护英、日、韩；繁体未提供时自动转换简体 |

版本按数字分段比较，因此 `0.7.4.10` 高于 `0.7.4.2`。同基础版本的 Beta 排在正式版前，渠道仍单独匹配。范围不会自动扩大到其他分支。各语言标题最多 120 字符，正文最多 6000 字符；文件最多 128 KiB、共 64 条，超出或存在非法字段值时不采用此次配置。

标题、正文跟随应用界面语言，不跟随 AI 回答语言。英文、日文或韩文缺失时优先使用英文，再回退简体；繁体缺失时由简体自动转换。按钮和系统提示由应用提供对应翻译。所有语言共用同一编号及已读状态，切换语言不重复弹出已确认的公告。

不稳定提示针对当前已安装版本，不等同于 ENF。用户可以继续使用；已有适用的正式更新时提供“前往更新”。它不会修改安装资格、绕过校验、关闭功能或强制下载安装。修复版尚未发布也能先发警告。

## 获取时机与失败处理

- 启动、手动检查更新及已有的六小时更新任务复用检查机会，不新增后台任务；没有系统推送，不能保证发布后立刻送达。
- 自动刷新间隔六小时；失败后十五分钟内不自动重试。手动检查可提前刷新，但十五秒内合并重复请求。
- 官方固定文件地址优先，失败后按现有镜像开关回退一次。仅请求公开配置，不传题目、API Key、设备标识或 GitHub 凭据。
- 使用 ETag 条件请求；缓存最多用于展示七天且仍受每条到期时间约束。已缓存内容在前台按预约开始、到期及缓存失效时间重新判断，不为此重复联网。关闭后台更新通知后不单独创建公告后台任务，前台检查仍可读取。
- 收到更高修订的合法空配置会立即清除待显示内容。旧修订不能覆盖新修订；同顶层修订的不同内容会被忽略，应增加顶层修订重新发布。
- 网络、镜像缓存及系统后台限制都可能延迟发现；404、解析失败或超时不会把应用锁住。

配置源 URL 只允许本仓库 main 分支的上述固定路径。更换发布位置需要修改客户端白名单。Compatible v0.7.5 已接入此能力，读取同一份 main 配置并匹配 compat 分支；旧兼容版本仍需先升级。
