个人自用安卓学习工具，用于拍照/图文提问、AI 解答、错题整理与复习，无账号体系或自有服务器。
由 zsz 开发，DeepSeek 与 GPT 辅助编写。
安装包和已发布版本以 [GitHub Releases](https://github.com/ShizhenZhou/StudyAssistant/releases) 为准。

## 功能

- 📷 拍照或图文提问，最多 3 张图；自动/手动框选，支持题目与手写作答批改。
- 🤖 流式解答、附图追问、中止与继续生成、同类题练习，支持 KaTeX 公式显示。
- 🧠 AI 管理分为 API 管理（含用量统计）、AI 切图、解题设置、自定义要求四个子页。快速模式与思考模式均使用 `deepseek-flash`，分别关闭/开启思考；可配置自定义要求和输出语言。
- 📚 错题本支持分类、标签、搜索、排序及批量处理。
- 🕘 解题记录保存首次解题、图文提问和批改，保留最近 **200 条且不超过 30 天**；后续追问更新同一条，按首次时间排序，从错题本/复习打开不新增记录。
- 🏷 标签整理支持 AI 建议和手动分组，预览确认后才合并，可撤销最近一次合并。
- 📝 标签整理草稿自动保存；AI 分析可手动导出最近 20 条本机诊断。
- 📖 按 `0/1/2/4/7/15/30` 天排期复习，提供学习统计及每日提醒。
- 🌐 支持简体/繁体中文、英文、日文、韩文界面，以及主题和全局字号调整；AI 输出语言单独配置。
- 📦 备份管理支持 ZIP 压缩包（`.zip`）、图片去重和大备份分卷，也兼容导入旧 v3 JSON。单文件命名为 `SABak-时间戳.zip`，分卷追加 `-1of3`，恢复时多选全部分卷；同题号保留本机内容，仅为新题引入分类和标签。
- 🗄️ 自动备份使用 `SABak_auto-` 前缀，每天打开应用后约30秒择机执行；当天已有完整手动或自动备份、空错题本时跳过；其他日期即使内容未变也每天备份一次。等待中的自动计划可由“立即备份一次”接管，任务不依赖页面保持打开。开始前完整自动备份超过 **3 套**时先保留最新 **2 套**，成功后保留 **3 套**；旧命名自动备份也参与清理，手动备份、损坏、缺卷及无法识别的文件保留。前台成功显示气泡，后台最终失败发系统通知（需允许通知权限）。
- 💾 保存失败可重试，已落盘副本支持重启恢复；冲突不覆盖，待保存内容可手动导出。
- 💬 重新生成保留旧答案直至成功；中断对话以独立本机草稿保存，可从主页或数据管理恢复。草稿不进入普通备份；救援导出供人工协助恢复。
- ↩️ 删除错题、解题记录与分类后有 3 秒撤销窗口；复习固定本轮筛选范围，AI 批改建议需确认。今日/本周/连续天数和趋势按最近复习日期估算。
- ⬆️ 应用内检查更新，由 Android 系统后台下载，离开页面后继续，返回恢复进度；持续通知显示进度并可点按回到更新页，通知受限时仍继续系统下载。实时胶囊由手机系统决定，需真机确认；网络恢复后尝试续传，支持主动取消。同版本比较包的 UTC 构建时间；下载前读取发布兼容清单，系统低于安装包要求时不下载，安装前核对实际最低系统版本、签名证书、版本及 SHA-256 摘要。

## 数据与隐私

错题、解题记录与复习数据库保存在本机。AI 功能将必要的题干、图片、上下文、自定义要求、相关分类/标签名和参数直接发往 **DeepSeek 官方 API**，使用用户自备 Key 鉴权，不经过开发者服务器。Key 以 Android Keystore 加密保存在本机。

主动点击“标签整理 → AI 分析”会发送完整标签的编号、名称与关联题数，不发送题目正文、答案或图片。检查更新及下载安装包访问 GitHub，不携带题目内容。无统计上报。

自动备份仅写入用户通过系统文件选择器（SAF）选定的文件夹，本应用不主动云同步；若选择网盘目录，网盘应用可能自行同步。崩溃日志和 AI 分析诊断仅在手动导出时写入用户选择的位置。

## 技术栈

Kotlin **2.4.21** · Jetpack Compose / Material3 · MVVM · Room **2.8.5**（DB v10）· Retrofit / OkHttp（SSE）· kotlinx.serialization · CameraX · WebView / KaTeX · Navigation Compose · WorkManager **2.12.0**（一次性备份任务）· AlarmManager · Android Keystore。

构建使用 AGP **9.4.0**、Gradle wrapper **9.8.2** 和 JDK **25**；compileSdk / targetSdk **37**、minSdk **36**（Android **16+**）、build-tools **36.0.0**。当前备份格式 Bak v4（原生 ZIP / DEFLATE；支持导入 v3 JSON），数据兼容细节见 [DATA_SCHEMA.md](docs/DATA_SCHEMA.md)。

## 开发与测试

Develop/功能分支开发 → 本地最小必要验证 → 必要时Beta真机测试与ADB辅助 → 相关修正/补验 → 规范合并main → 一次CI构建 → 签名发布。

默认 `tools/check-project.ps1` 仅检查差异和敏感内容；确有必要才使用 `-Compile` 或 `-TestClass` 指定类/方法。无默认全套或模拟器，不本地/在线重复测试。功能开发不自行扩大测试流程；交互效果优先请用户真机确认。详见 [开发流程](docs/development.md) 和 [AGENTS.md](AGENTS.md)。

## 密钥与发布

CI仅手动构建未签名APK及身份清单，不默认JVM、工具或设备测试；push/PR/tag不触发重复构建。提交与合并标题使用feat:/fix:/build:/ci:等规范前缀。

完成验证、合并并推送main后，使用 `tools/release.ps1 start --version VERSION` → `status` → `publish --run RUN_ID`。原证书与lineage只在本地使用，核对包身份/代码资源并真实下载校验归档。保留最低系统要求和正式/测试渠道说明；不移动已有标签。Key、签名材料、题库、备份及手机日志不得提交或上传CI。
