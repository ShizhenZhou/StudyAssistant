個人自用安卓學習工具，用於拍照/圖文提問、AI 解答、錯題整理與複習，無賬號體系或自有服務器。
由 zsz 開發，DeepSeek 與 GPT 輔助編寫。
安裝包和已發布版本以 [GitHub Releases](https://github.com/ShizhenZhou/StudyAssistant/releases) 為準。

## 功能

- 📷 拍照或圖文提問，最多 3 張圖；自動/手動框選，支持題目與手寫作答批改。
- 🤖 流式解答、附圖追問、中止與繼續生成、同類題練習，支持 KaTeX 公式顯示。
- 🧠 AI 管理分為 API 管理（含用量統計）、AI 切圖、解題設置、自定義要求四個子頁。快速模式與思考模式均使用 `deepseek-flash`，分別關閉/開啟思考；可配置自定義要求和輸出語言。
- 📚 錯題本支持分類、標簽、搜索、排序及批量處理。
- 🕘 解題記錄儲存首次解題、圖文提問和批改，保留最近 **200 條且不超過 30 天**；後續追問更新同一條，按首次時間排序，從錯題本/複習打開不新增記錄。
- 🏷 標簽整理支持 AI 建議和手動分組，預覽確認後才合並，可撤銷最近一次合並。
- 📝 標簽整理草稿自動保存；AI 分析可手動導出最近 20 條本機診斷。
- 📖 按 `0/1/2/4/7/15/30` 天排期複習，提供學習統計及每日提醒。
- 🌐 支持簡體/繁體中文、英文、日文、韓文界面，以及主題和全局字號調整；AI 輸出語言單獨配置。
- 📦 備份管理支持 ZIP 壓縮包（`.zip`）、圖片去重和大備份分卷，也兼容導入舊 v3 JSON。單文件命名為 `SABak-时间戳.zip`，分卷追加 `-1of3`，恢復時多選全部分卷；同題號保留本機內容，僅為新題引入分類和標簽。
- 🗄️ 自動備份使用 `SABak_auto-` 前綴，每天打開應用後約30秒擇機執行；當天已有完整手動或自動備份、空錯題本時跳過；其他日期即使內容未變也每天備份一次。等待中的自動計劃可由“立即備份一次”接管，任務不依賴頁面保持打開。開始前完整自動備份超過 **3 套**時先保留最新 **2 套**，成功後保留 **3 套**；舊命名自動備份也參與清理，手動備份、損壞、缺卷及無法識別的文件保留。前臺成功顯示氣泡，後臺最終失敗發系統通知（需允許通知權限）。
- 💾 保存失敗可重試，已落盤副本支持重啟恢復；衝突不覆蓋，待保存內容可手動導出。
- 💬 重新生成保留舊答案直至成功；中斷對話以獨立本機草稿保存，可從主頁或數據管理恢復。草稿不進入普通備份；救援導出供人工協助恢復。
- ↩️ 刪除錯題、解題記錄與分類後有 3 秒撤銷窗口；複習固定本輪篩選範圍，AI 批改建議需確認。今日/本週/連續天數和趨勢按最近複習日期估算。
- ⬆️ 應用內檢查更新，由 Android 系統後臺下載，離開頁面後繼續，返回恢復進度；持續通知顯示進度並可點按回到更新頁，通知受限時仍繼續系統下載。實時膠囊由手機系統決定，需真機確認；網絡恢復後嘗試續傳，支持主動取消。同版本比較包的 UTC 構建時間；下載前讀取發布兼容清單，系統低於安裝包要求時不下載，安裝前核對實際最低系統版本、簽名證書、版本及 SHA-256 摘要。

## 數據與隱私

錯題、解題記錄與複習數據庫保存在本機。AI 功能將必要的題幹、圖片、上下文、自定義要求、相關分類/標簽名和參數直接發往 **DeepSeek 官方 API**，使用用戶自備 Key 鑑權，不經過開發者服務器。Key 以 Android Keystore 加密保存在本機。

主動點擊“標簽整理 → AI 分析”會發送完整標簽的編號、名稱與關聯題數，不發送題目正文、答案或圖片。檢查更新及下載安裝包訪問 GitHub，不攜帶題目內容。無統計上報。

自動備份僅寫入用戶通過系統文件選擇器（SAF）選定的文件夾，本應用不主動雲同步；若選擇網盤目錄，網盤應用可能自行同步。崩潰日誌和 AI 分析診斷僅在手動導出時寫入用戶選擇的位置。

## 技術棧

Kotlin **2.2.20** · Jetpack Compose / Material3 · MVVM · Room **2.8.4**（DB v10）· Retrofit / OkHttp（SSE）· kotlinx.serialization · CameraX · WebView / KaTeX · Navigation Compose · WorkManager **2.12.0**（一次性備份任務）· AlarmManager · Android Keystore。

構建使用 AGP **8.13.0**、Gradle wrapper **8.14** 和 JDK **21**；compileSdk / targetSdk **37**、minSdk **36**（Android **16+**）、build-tools **36.0.0**。當前備份格式 Bak v4（原生 ZIP / DEFLATE；支持導入 v3 JSON），數據兼容細節見 [DATA_SCHEMA.md](DATA_SCHEMA.md)。

## 密鑰與發布

本倉庫公開，API Key、令牌、簽名材料、本地配置、真實題庫與備份不得提交或作為CI附件。提交前掃描入口為 .githooks；掃描不能替代差異審閱。

正式流程：**本地基礎檢查 → 合並main → 一次完整CI → 本地簽名 → 發布與下載校驗歸檔**。CI只編譯未簽名候選包並運行人工數據測試；簽名私鑰及口令僅在本機使用，不上傳GitHub。簽名沿用原證書與lineage，不重編譯，並校驗代碼資源與候選包一致。

通用入口 tools/release.ps1 提供 start/status/verify/publish，記錄本地進度並支持續跑；main推送和tag不重複構建，不移動已有標簽，不自動替換已發布版本。詳細命令、上傳邊界和Git/API分工見[開發流程](docs/development.md)。內部設計、排查及逐版本過程只在本地歸檔。
